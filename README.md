# lieradio-search
リエラジの出演者の検索を行うアプリケーション

## 📌 概要

リエラジの出演者を検索できるWebアプリケーションです。
放送回数が多くなるにつれて、「あの人が出ていた回どれだっけ？」という課題を解決するために開発しました。

---

## 🎯 解決したい課題

* 放送回が多く、新規リスナーが過去回を探しづらい
* 特定の出演者の回を一覧で見たいニーズがある
* YouTubeのプレイリストでは検索性が弱い

---

## 🛠️ 主な機能

* 出演者名での検索
* 放送回ごとの出演者一覧表示
* 該当回のYouTubeリンク取得

---

## 🧩 技術スタック

* Backend：Java / Spring Boot
* Database：MySQL
* ORM：MyBatis
* API仕様：REST / JSON
* ドキュメント：Swagger（OpenAPI）
* インフラ：AWS（EC2 / RDS / ALB）
* その他：Git / GitHub

---

## 💡 工夫した点

* 出演者検索に対応するため、複数テーブルを結合した検索APIを実装
* 動的SQLを用いて検索条件の柔軟性を確保
* ステータス管理と同様に、データの一貫性を意識した設計
